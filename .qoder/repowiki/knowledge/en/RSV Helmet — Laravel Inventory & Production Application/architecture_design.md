The root is a standard Laravel 13 project whose children are wired together by the framework's PSR-4 autoloader (`App\` → `app/`, `Database\Factories\` → `database/factories/`, `Tests\` → `tests/`). The domain layer (`business_domain`) owns Eloquent models and services; the database schema lives in `database/migrations` and is consumed by both the domain and the test suite. The HTTP layer (`http_layer`) registers routes and an Artisan command that call into the domain, while the Filament admin panel (`filament_admin_ui`) and the Livewire request form (`livewire_components`) provide the user-facing surfaces over the same models. Frontend assets (Blade + Tailwind 4 + Vite) are built via `vite.config.js` and served alongside PHP through Docker Compose (`app` + `db` containers). Deployment is orchestrated by `deploy.sh`, which pulls a prebuilt image from GHCR and runs post-deploy cache optimizations (`config:cache`, `route:cache`, `view:cache`, `storage:link`).
