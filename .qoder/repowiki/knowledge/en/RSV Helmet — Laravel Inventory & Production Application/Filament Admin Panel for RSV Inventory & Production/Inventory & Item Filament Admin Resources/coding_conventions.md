- Every resource declares `$navigationGroup = 'Data Master'` or `'Gudang'`, a `$navigationIcon` from the heroicon-o set, localized `$navigationLabel`/`modelLabel`/`pluralModelLabel`, and a numeric `$navigationSort` to order entries in the sidebar.
- CRUD pages are registered via `getPages()` returning `List*::route('/')`, `Create*::route('/create')`, and `Edit*::route('/{record}/edit')`, keeping URL routes co-located with the resource definition.
- Tables use `->infinite(perPage: 50)` for infinite-scroll lists, and boolean/status columns are rendered with `IconColumn::make(...)->boolean()` or a `badge()` column whose color is driven by a `match` expression.
- User-facing labels, helper text, validation messages, and notifications are written in Indonesian (e.g. 'Kode barang', 'Stok minimum', 'Barang ini sudah memiliki stok di gudang yang dipilih').
- Large select inputs use the custom `InfiniteSelect` component with `getPaginatedOptionsUsing` returning `['options' => ..., 'hasMore' => ...]` keyed by model id and displaying `"{$item->item_code} — {$item->item_name}"`.
- Stock-affecting operations (bulk transfer, deletion, creation) delegate persistence to `StockMovementService` resolved via `app(StockMovementService::class)` and wrap multi-row work in `DB::transaction`, surfacing errors through `ValidationException::withMessages` caught to show persistent Filament notifications.
