Single-resource module built on Filament v3's `Resource` class (`ItemRequestResource.php`) with three sibling sub-folders following Filament conventions:
- `Pages/` — custom Livewire pages extending `EditRecord` and `InfiniteScrollListRecords`, bound to the resource via `$resource = ItemRequestResource::class` and registered through `getPages()`.
- `RelationManagers/` — `LinesRelationManager` renders the `lines` Eloquent relationship as an inline table with an edit action using a custom `InfiniteSelect` component for mapping requested items to inventory items.
- Root file defines the form (read-only sections for requester, status/approval metadata), the table (with status badge coloring and select filters), and two static `Action`s (`approveAction`, `rejectAction`) that open modals delegating business logic to `App\Services\ItemRequestService`. The resource is placed under navigation group `Gudang`, hides create, and shows a warning badge counting pending requests. Approval gating checks `ItemRequestSetting` for configured origin/destination warehouses before exposing the approve action.
