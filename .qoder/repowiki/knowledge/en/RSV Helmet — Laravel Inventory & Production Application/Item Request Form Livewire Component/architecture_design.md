Single-component module under the standard Livewire layout: `app/Livewire/ItemRequestForm.php` is a Livewire `Component` extending the base class, decorated with `#[Layout('layouts.public')]` and `#[Title('Permintaan Barang')]`. It owns all public state (`requester_name`, `division_id`, `note`, `lines[]`, `website` honeypot, `submitted`/`submittedCode`/`submittedId`) and exposes actions (`addLine`, `removeLine`, `selectItem`, `clearSelectedItem`, `submit`, `createAnother`). The Blade view at `resources/views/livewire/item-request-form.blade.php` renders both the input form (when `$submitted` is false) and a success/ticket confirmation screen (when true), reusing `livewire.partials.item-request-preview` to embed the existing `item-requests.document` template in preview mode. Client-side interactivity beyond Livewire is delegated to Alpine.js (`x-data`, `x-init`, `@click`) for clipboard copy and the Web Share API flow via `window.prepareItemRequestPdf` / `window.shareItemRequestPdf`. Data access stays inside the component's `render()` method, which loads active `Division`s, active `Item`s with `baseUom`, per-line search results, and a signed temporary URL for the generated PDF.
