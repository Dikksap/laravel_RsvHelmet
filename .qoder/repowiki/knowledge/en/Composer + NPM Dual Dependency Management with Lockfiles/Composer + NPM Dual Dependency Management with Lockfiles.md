## Approach

The project uses two independent package managers, one per runtime:

- **PHP**: Composer (`composer.json` + `composer.lock`) for Laravel/Filament and PHP packages.
- **JavaScript/Node**: NPM (`package.json` + `package-lock.json`) for Vite, Tailwind CSS, and build tooling.

There is no vendoring of PHP or JS source code into the repo — dependencies are resolved at install time from public registries (Packagist and npmjs.org). No private registry, `GOPRIVATE`, or custom repository configuration is present in either manifest.

## Key Files

- `composer.json` — declares PHP runtime deps, dev deps, autoload PSR-4 namespaces, Composer scripts, and plugin allow-list.
- `composer.lock` — pinned lockfile generated by Composer; committed to the repo.
- `package.json` — declares Node devDependencies and an optional dependency.
- `package-lock.json` — pinned lockfile generated by NPM v3 lockfile format; committed to the repo.
- `.npmrc` — NPM config: `ignore-scripts=true`, `audit=true`.
- `vite.config.js` — ties the Node build pipeline together (build/dev scripts).

## Architecture & Conventions

### PHP (Composer)

- Runtime dependencies live under `require`: `laravel/framework ^13.17`, `filament/filament ^5.0`, `barryvdh/laravel-dompdf ^3.1`, `fibtegis/filament-infinite-scroll ^2.0`, `mrpunyapal/filament-infinite-select ^0.2`, plus `php ^8.3`.
- Dev/test dependencies live under `require-dev`: `fakerphp/faker`, `laravel/pint`, `mockery/mockery`, `nunomaduro/collision`, `phpunit/phpunit ^12.5.12`, `laravel/boost`, `laravel/pail`, `laravel/pao`.
- Autoloading follows PSR-4: `App\` → `app/`, `Database\Factories\` → `database/factories/`, `Database\Seeders\` → `database/seeders/`, `Tests\` → `tests/`.
- Composer scripts orchestrate setup: a `setup` script runs `composer install`, copies `.env.example`, generates the app key, runs migrations, then `npm install --ignore-scripts` and `npm run build`; a `dev` script disables the process timeout and runs `artisan dev`; a `test` script clears config before `artisan test`.
- Post-install hooks: `post-autoload-dump` runs Laravel's autoloader dump, package discovery, and `filament:upgrade`; `post-update-cmd` publishes Laravel assets; `post-root-package-install` and `post-create-project-cmd` seed the environment and database.
- Plugin security: only `pestphp/pest-plugin` and `php-http/discovery` are explicitly allowed via `config.allow-plugins`; all others default to blocked.
- Stability policy: `minimum-stability: stable` with `prefer-stable: true`.
- Composer config: `optimize-autoloader: true`, `preferred-install: dist`, `sort-packages: true`.

### JavaScript (NPM/Vite)

- All JS dependencies are `devDependencies`: `@tailwindcss/vite ^4.0.0`, `concurrently ^10.0.3`, `laravel-vite-plugin ^3.1`, `tailwindcss ^4.0.0`, `vite ^8.0.0`.
- One optional runtime dependency: `@laravel/multiplex ^0.4.1` (macOS/Linux only, requires Node >= 22.13.0).
- The package is marked `"private": true` and uses ESM (`"type": "module"`).
- Scripts: `build` → `vite build`, `dev` → `vite`.
- `.npmrc` enforces `ignore-scripts=true` globally (no native postinstall scripts run) and enables `audit=true` for vulnerability scanning.

## Conventions & Constraints

- **Lockfiles are committed** — both `composer.lock` and `package-lock.json` are tracked in version control, pinning exact transitive versions for reproducible installs.
- **No vendored third-party source** — PHP and JS libraries are not checked in; they are installed fresh from Packagist/npm during CI/build.
- **Public registries only** — no custom repositories, private packagist mirrors, or npm registry overrides are configured in either manifest or `.npmrc`.
- **Plugin allowlist enforced** — Composer will refuse to execute plugins not listed under `config.allow-plugins` unless explicitly permitted.
- **Native/NPM scripts disabled** — `.npmrc ignore-scripts=true` prevents any package from running arbitrary code during install; Composer's `setup` script passes `--ignore-scripts` to `npm install` as well.
- **Audit enabled** — NPM audit is turned on via `.npmrc`, so vulnerability checks run on every install.
