Composer script `composer setup` runs install, env copy, key generate, migrate, npm install, and build. The sync command is invoked via `php artisan sync:external-barang --warehouse=ID [--batch=ID] [--kode-batch=BC001] [--limit=100] [--all-pages] [--status=FINISHGOOD] [--dry-run]`. Production deployment uses Dockerfiles under `docker/production/` with nginx.conf, php.ini, supervisord.conf, and `deploy.sh`.
