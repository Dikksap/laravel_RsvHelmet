Standard Laravel 13 application on PHP 8.3 with the following internal layers:
- `app/Models` — Eloquent models for all domain entities (Item, Warehouse, InventoryBalance, ProductionBatch, StockOpname, ItemRequest, etc.), each paired with a factory in `database/factories`.
- `app/Filament/Resources/*` — one Filament Resource per model, each split into `Pages/{Create,Edit,List}` plus optional `RelationManagers` for child collections; resources are auto-discovered via `AdminPanelProvider::discoverResources`.
- `app/Filament/Pages` — custom non-resource pages (Dashboard, BomBuilder, BatchRealization, WarehouseStock*, DaftarBarangEksternal) rendered through Blade views under `resources/views/filament/pages`.
- `app/Filament/Imports` / `app/Filament/Exports` — CSV import/export classes wired to Filament's import/export pipeline.
- `app/Services` — pure business logic layer (`BomExplosionService`, `BatchProgressService`, `BatchRequirementService`, `StockMovementService`, `StockOpnameService`, `ExternalBarangApiService`, `ExternalBarangSyncService`, `ItemRequestService`) consumed by controllers/resources.
- `app/Livewire` — single Livewire component `ItemRequestForm` powering the public `/permintaan-barang` route.
- `app/Http/Controllers` — minimal HTTP controllers (only `ItemRequestPdfController`); most UI is Filament-driven.
- `app/Console/Commands` — CLI entry point `SyncExternalBarangCommand` orchestrating external barang sync.
- `app/Providers/Filament/AdminPanelProvider.php` registers the admin panel at `/admin`, groups navigation into Gudang / Permintaan Barang / Produksi / Integrasi Eksternal / Data Master, and injects brand-lockup partials via `PanelsRenderHook`.
- Public routes live in `routes/web.php`; console routes in `routes/console.php`.
- Database schema is versioned via timestamped migrations under `database/migrations`, seeded by `MasterDataSeeder` / `FinishGoodItemSeeder` / `MasterItemSeeder`.
- Deployment targets Docker Compose (dev) and a separate `Dockerfile.prod` + `docker-compose.prod.yml` driven by `deploy.sh`.
