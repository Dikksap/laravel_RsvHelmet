The root is a standard Laravel project whose children are wired together by the framework's PSR-4 autoloader (`App\` → `app/`, `Database\Factories\` → `database/factories/`, `Tests\` → `tests/`). The domain layer owns Eloquent models and services; the database schema (migrations, seeders, factories) is consumed uniformly by the domain, the Filament admin resources, the Livewire form, and the test suite. The HTTP layer registers routes and an external-barang sync Artisan command that call into the domain, while the Filament admin panel and the Livewire request form provide user-facing surfaces over the same models. Frontend assets (Blade + Tailwind 4 + Vite) are built via `vite.config.js` and served alongside PHP through Docker Compose (`app` + `db` containers). Deployment is orchestrated by `deploy.sh`, which pulls a prebuilt image from GHCR and runs post-deploy cache optimizations (`config:cache`, `route:cache`, `view:cache`, `storage:link`).
