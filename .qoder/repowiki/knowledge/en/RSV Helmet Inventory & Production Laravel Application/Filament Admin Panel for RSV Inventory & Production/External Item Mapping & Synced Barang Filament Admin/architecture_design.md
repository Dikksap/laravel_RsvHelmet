Two sibling Filament `Resource` classes under `app/Filament/Resources/`: `ExternalItemMappingResource` (CRUD pages in a `Pages/` sub-namespace) manages the `ExternalItemMapping` model, wiring an `ExternalBarangApiService` into a live `Select` that auto-fills variant fields and an `InfiniteSelect` for paginated lookup of active `Item`s; `ExternalSyncedBarangResource` is read-only (empty form, no actions/bulkActions) and displays the `ExternalSyncedBarang` history with relation columns (`item`, `mapping`, `warehouse`, `movement`) and a status badge derived from the external API state. Both resources register themselves in the `Gudang` navigation group via `navigationGroup` / `navigationSort` and declare their custom Pages through `getPages()` returning route mappings.
