Two sibling Filament `Resource` classes — `ProductionBatchResource` (group 'Produksi') and `StockOpnameResource` (group 'Gudang') — each follow the standard Filament layout: a top-level Resource class wiring `$model`, navigation metadata, `form()`, `table()`, `getRelations()`, and `getPages()`. Each resource is split into sub-namespaces `Pages/` for route-bound actions (`List*`, `Create*`, `View*`, optional `Edit*`) and `RelationManagers/` for nested child tables (Items/Materials/RawMaterials/Movements for batches; Lines/Movements for opnames). Status-driven UI is centralized through Eloquent model constants (`STATUS_RUNNING`, `STATUS_COMPLETED`, etc.) and shared `statusOptions()` helpers. Navigation badges count active records (running batches, draft opnames) to surface work-in-progress at the sidebar level. Both resources use infinite-scroll tables (`->infinite(perPage: 50)`), grouped sections in forms via `Section::make(...)`, and status columns rendered as colored badges derived from model-backed enums. The stock opname lines manager additionally exposes bulk header actions (fill-from-system, clear counts, CSV import/export) gated on `isDraft()` state.
