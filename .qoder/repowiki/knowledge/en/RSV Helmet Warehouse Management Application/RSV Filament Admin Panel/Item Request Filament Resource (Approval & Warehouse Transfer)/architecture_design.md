Single-resource module built on Filament v3's `Resource` class (`ItemRequestResource.php`) organized into three sibling sub-folders following Filament conventions:
- Root file defines the model binding, navigation metadata, read-only form sections (requester + status/approval metadata), the table with status badge coloring and select filters, two static `Action` factories (`approveAction`, `rejectAction`) used both in table record actions and page header actions, relation registration, and page routing.
- `Pages/` — custom Livewire pages extending `EditRecord` and `InfiniteScrollListRecords`, bound to the resource via `$resource = ItemRequestResource::class` and registered through `getPages()`; the edit page reuses the resource's approve/reject actions in its header.
- `RelationManagers/` — `LinesRelationManager` renders the `lines` Eloquent relationship as an inline table with an edit action using a custom `InfiniteSelect` component for mapping requested items to inventory items.

Dependency direction is one-way outward: this module depends on domain models (`ItemRequest`, `ItemRequestLine`, `ItemRequestSetting`, `InventoryBalance`, `Item`) and delegates all business mutations to `App\Services\ItemRequestService`; it does not mutate models directly. Approval gating checks `ItemRequestSetting` for configured origin/destination warehouses before exposing the approve action, and the modal pre-populates per-line defaults by loading `InventoryBalance` for the configured origin warehouse.
